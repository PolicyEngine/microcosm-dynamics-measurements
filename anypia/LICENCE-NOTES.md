# Copyright and distribution evidence

SSA's *Social Security Benefit Calculator User's Guide*, PDF page 3 (the first
substantive page, headed “Social Security Benefit Calculator”), states:

> The source program is not copyrighted. Distribution is encouraged, with acknowledgment to the Social Security Administration, Actuarial Services.

This is a statement about the calculator's source program. The guide does not
assign a named software licence in that passage. Credit for the calculator
source therefore remains with **Social Security Administration, Actuarial
Services**.
